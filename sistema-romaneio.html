Como preparar a tabela no Supabase (clique para ver o SQL)

Cole e execute isto uma vez no SQL Editor do seu projeto Supabase. Ele cria a tabela e libera leitura/escrita para a chave anon — adequado para uso interno/confiável, já que qualquer pessoa com essa chave poderá ler e alterar os romaneios.
